02
Time Series · Predictive Maintenance

Turbofan Engine
RUL Prediction

Predicted the Remaining Useful Life (RUL) of turbofan engines using NASA's CMAPSS sensor dataset. Applied classical ML with RandomForest as a baseline, then built LSTM networks to capture temporal degradation patterns — cutting MAE from ~20 to ~11 cycles (45% improvement).

LSTM RandomForest Scikit-learn Pandas Seaborn NASA CMAPSS Time Series
↓ 45% MAE reduction — LSTM outperforms RandomForest on sequential sensor data
Model Comparison — MAE (lower is better)
RandomForest Regression
Mean Absolute Error ~20 cycles
LSTM — Deep Learning
Mean Absolute Error ~11 cycles
Why LSTM?
Engine sensor readings are sequential — LSTM's memory cells capture long-range degradation trends across engine cycles that tree-based models cannot model effectively.
